# Pie and donut charts (`pp.pieplot`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `pp.pieplot` — a themed part-of-whole plotter with donut support, palette/edge/hatch inheritance, legend stashing and value annotation — closing #268.

**Architecture:** A shared wedge renderer under `src/publiplots/plot/wedge/`, split so that `geometry.py` computes a tree and its angular layout as pure data (no matplotlib), `colour.py` derives per-node colours, and `draw.py` constructs `matplotlib.patches.Wedge` artists while emitting annotate metadata that **holds each artist from construction**. `pie.py` is a thin public function over that renderer. The geometry and colour layers are written for the general multi-level case and unit-tested at depth 3, so the sunburst (a separate plan) adds a public function rather than a rewrite.

**Tech Stack:** Python >= 3.9, matplotlib >= 3.7, pandas >= 1.3, numpy >= 1.21. Tests with pytest.

**Spec:** `docs/superpowers/specs/2026-09-25-pie-sunburst-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- **Run tests with** `uv run --extra dev python -m pytest`. The `python -m` matters: with bare `pytest`, uv's injected packages are not on `sys.path`. Append `--no-cov` when running a single test for speed.
- **Python 3.9 floor.** Use `from __future__ import annotations` plus `typing.Optional`/`List`/`Dict`/`Tuple`/`Union`. No `X | Y` unions at runtime.
- **Figures are sized in millimetres.** Use `pp.subplots(axes_size=(w_mm, h_mm))`. Never call `plt.subplots`, `tight_layout` or `ax.legend` directly — they bypass the layout reactor and the legend claim system.
- **Stroke classification.** `pp.rcParams["edgewidth"]` (0.75) for strokes that *outline a shape* — wedge borders and leader lines both qualify. `plt.rcParams["lines.linewidth"]` is for strokes that *are* the data; nothing in this plan uses it.

- **Every test file that touches figures** carries its own `@pytest.fixture(autouse=True)` calling `plt.close("all")`. There is no `tests/conftest.py`.
- **Float comparisons use `pytest.approx`.** Exact equality on categorical positions has produced three false failures in this codebase.
- **Attribution:** never add `Co-Authored-By`, "Generated with", a robot emoji, or any AI marker to a commit message, PR, issue, changelog entry, code comment or docstring. Commit as the configured git author.

```python
"""Tree construction and angular layout for wedge charts.

Pure data: this module imports no matplotlib and creates no artists. A
frame becomes a list of :class:`WedgeNode`, and nodes become a list of
:class:`WedgePlacement` carrying angles in degrees and radii in axes
units. Keeping the layout free of artists is what lets the tree be
tested as data rather than by measuring a rendered figure.
"""
from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Dict, List, Optional, Sequence, Tuple

import pandas as pd

from publiplots.annotate._builders import _categorical_order

_DIRECTIONS = ("clockwise", "counterclockwise")


@dataclass(frozen=True)
class WedgeNode:
    """One node of the composition tree.

    Fields:
        path: keys from the root ring to this node; ``len(path) == depth + 1``.
        value: aggregated value; for an internal node, the sum of its children.
        depth: 0 for the innermost ring.
        parent: the parent's path, or None at depth 0.
        sibling_index: position among the nodes sharing this parent.
        sibling_count: how many nodes share this parent.
    """

    path: Tuple[Any, ...]
    value: float
    depth: int
    parent: Optional[Tuple[Any, ...]]
    sibling_index: int
    sibling_count: int


@dataclass(frozen=True)
class WedgePlacement:
    """A node's angular and radial extent.

    ``theta0 < theta1`` always, matching the argument order of
    ``matplotlib.patches.Wedge(center, r, theta1, theta2)``.
    """

    node: WedgeNode
    theta0: float
    theta1: float
    r_inner: float
    r_outer: float


def build_nodes(
    data: pd.DataFrame,
    levels: List[str],
    value: Optional[str] = None,
    order: Optional[Dict[str, Sequence]] = None,
    sort: bool = False,
) -> List[WedgeNode]:
    """Aggregate ``data`` into a composition tree, in draw order.

    A parent's value is always the sum of its children; internal nodes are
    never read from the frame. Rows with a NaN value are dropped, as are
    groups summing to zero -- a zero wedge draws nothing, so a record for
    it would describe no artist.
    """
    if sort and order:
        raise ValueError(
            "sort=True cannot be combined with order=; pass one or the other."
        )
    if not levels:
        raise ValueError("at least one level is required")

    frame = data.loc[:, list(levels) + ([value] if value else [])].copy()
    if value is None:
        value = "_count"
        frame[value] = 1.0
    frame = frame.dropna(subset=[value] + list(levels))
    if (frame[value] < 0).any():
        raise ValueError(
            "pieplot: negative values are not supported -- a negative wedge "
            "has no meaning in a part-of-whole chart."
        )

    order = dict(order or {})
    leaf_sums = frame.groupby(list(levels), observed=True, dropna=True)[value].sum()

    nodes: List[WedgeNode] = []

    def _levels_at(prefix: Tuple[Any, ...]) -> List[Any]:
        """Distinct keys of the next level below ``prefix``, in draw order."""
        depth = len(prefix)
        col = levels[depth]
        mask = pd.Series(True, index=frame.index)
        for i, key in enumerate(prefix):
            mask &= frame[levels[i]] == key
        present = frame.loc[mask, col]
        if present.empty:
            return []
        return list(_categorical_order(present, order.get(col)))

    def _subtree_sum(prefix: Tuple[Any, ...]) -> float:
        if len(prefix) == len(levels):
            return float(leaf_sums.get(prefix if len(prefix) > 1 else prefix[0], 0.0))
        return sum(_subtree_sum(prefix + (k,)) for k in _levels_at(prefix))

    def _walk(prefix: Tuple[Any, ...]) -> None:
        keys = _levels_at(prefix)
        entries = [(k, _subtree_sum(prefix + (k,))) for k in keys]
        entries = [(k, v) for k, v in entries if v > 0]
        if sort:
            entries.sort(key=lambda kv: kv[1], reverse=True)
        count = len(entries)
        for index, (key, total) in enumerate(entries):
            path = prefix + (key,)
            nodes.append(WedgeNode(
                path=path,
                value=float(total),
                depth=len(prefix),
                parent=prefix if prefix else None,
                sibling_index=index,
                sibling_count=count,
            ))
            if len(path) < len(levels):
                _walk(path)

    _walk(())
    return nodes


def total_value(nodes: List[WedgeNode]) -> float:
    """Sum of the root ring, which is the whole the chart is a part of."""
    return float(sum(n.value for n in nodes if n.depth == 0))


def layout(
    nodes: List[WedgeNode],
    *,
    start_angle: float = 90.0,
    direction: str = "clockwise",
    donut: float = 0.0,
    n_levels: int = 1,
) -> List[WedgePlacement]:
    """Assign each node an angular span and a radial band."""
    if direction not in _DIRECTIONS:
        raise ValueError(
            f"direction must be one of {list(_DIRECTIONS)}; got {direction!r}"
        )
    if not 0.0 <= donut < 1.0:
        raise ValueError(f"donut must be in [0, 1); got {donut!r}")

    total = total_value(nodes)
    if total <= 0:
        return []

    by_parent: Dict[Optional[Tuple[Any, ...]], List[WedgeNode]] = {}
    for node in nodes:
        by_parent.setdefault(node.parent, []).append(node)

    # Fraction of the full circle at which each node's span begins, walking
    # the tree in draw order so a child starts where its parent does.
    starts: Dict[Tuple[Any, ...], float] = {}

    def _assign(parent: Optional[Tuple[Any, ...]], cursor: float) -> None:
        for node in by_parent.get(parent, []):
            starts[node.path] = cursor
            _assign(node.path, cursor)
            cursor += node.value / total

    _assign(None, 0.0)

    band = (1.0 - donut) / n_levels
    places: List[WedgePlacement] = []
    for node in nodes:
        frac0 = starts[node.path]
        frac1 = frac0 + node.value / total
        if direction == "clockwise":
            theta_a = start_angle - frac1 * 360.0
            theta_b = start_angle - frac0 * 360.0
        else:
            theta_a = start_angle + frac0 * 360.0
            theta_b = start_angle + frac1 * 360.0
        places.append(WedgePlacement(
            node=node,
            theta0=theta_a,
            theta1=theta_b,
            r_inner=donut + band * node.depth,
            r_outer=donut + band * (node.depth + 1),
        ))
    return places
```

from __future__ import annotations

import pandas as pd
import pytest

from publiplots.plot.wedge.colour import blend, derive_colors, resolve_hue_values
from publiplots.plot.wedge.geometry import build_nodes


def _nested():
    return pd.DataFrame({

        "region": ["north", "north", "south", "south"],
        "score": [1.0, 2.0, 3.0, 4.0],

def test_blend_toward_white_and_black():

    assert blend("#ffffff", -0.5) == pytest.approx((0.5, 0.5, 0.5))
    assert blend("#336699", 0.0) == pytest.approx((0.2, 0.4, 0.6), abs=1e-6)

```python
"""Hue resolution and colour derivation for wedge charts.

Colour derives from the ``hue`` level, with descendants shaded from their
parent. Two scalars control it, both expressed as a **total span** rather
than a per-ring step: the outermost ring lands at ``depth_range``, and
siblings spread over ``sibling_range`` within their parent. Spans are
depth-independent; a per-ring step puts the rim 72% toward white at five
rings and needs retuning every time a level is added.
"""
from __future__ import annotations

from numbers import Number
from typing import Any, Dict, List, Optional, Tuple

import matplotlib.colors as mcolors
import pandas as pd

from publiplots.plot.wedge.geometry import WedgeNode

RGB = Tuple[float, float, float]


def blend(color, t: float) -> RGB:
    """Blend ``color`` toward white (``t > 0``) or black (``t < 0``)."""
    r, g, b = mcolors.to_rgb(color)
    if t == 0.0:
        return (r, g, b)
    target = 1.0 if t > 0 else 0.0
    f = abs(t)
    return (r + (target - r) * f,
            g + (target - g) * f,
            b + (target - b) * f)


def _is_numeric(series: pd.Series) -> bool:
    """Mirror seaborn's ``variable_type`` numeric rule, including its
    ``all_numeric`` fallback for object-dtype columns of numbers. Matching
    the rule rather than ``is_numeric_dtype`` alone is what #262 was about.
    """
    if pd.api.types.is_bool_dtype(series):
        return False
    if pd.api.types.is_numeric_dtype(series):
        return True
    values = series.dropna().tolist()
    return bool(values) and all(isinstance(v, Number) for v in values)


def resolve_hue_values(
    data: pd.DataFrame,
    levels: List[str],
    hue: Optional[str],
    nodes: List[WedgeNode],
) -> Tuple[Dict[Tuple[Any, ...], Any], bool]:
    """Map each node path to its hue value.

    ``hue`` defaults to the root level. A categorical hue must be constant
    within a node -- otherwise the node's colour is ambiguous, and taking
    the first silently is how a figure comes to misreport a group.
    """
    column = hue if hue is not None else levels[0]
    if column in levels:
        depth = levels.index(column)
        return ({n.path: n.path[depth] for n in nodes if len(n.path) > depth},
                False)

    if column not in data.columns:
        raise ValueError(f"hue={column!r} is not a column of data")

    continuous = _is_numeric(data[column])
    values: Dict[Tuple[Any, ...], Any] = {}
    for node in nodes:
        mask = pd.Series(True, index=data.index)
        for i, key in enumerate(node.path):
            mask &= data[levels[i]] == key
        present = data.loc[mask, column].dropna()
        if present.empty:
            continue
        if continuous:
            values[node.path] = float(present.mean())
            continue
        distinct = list(dict.fromkeys(present.tolist()))
        if len(distinct) > 1:
            raise ValueError(
                f"hue={column!r} is not constant within the wedge "
                f"{node.path!r}: found {distinct!r}. A wedge can only take "
                f"one colour; aggregate the column or pick a hue that is "
                f"constant within each group."
            )
        values[node.path] = distinct[0]
    return values, continuous


def derive_colors(
    nodes: List[WedgeNode],
    hue_values: Dict[Tuple[Any, ...], Any],
    palette: Dict[Any, Any],
    *,
    depth_range: float,
    sibling_range: float,
    n_levels: int,
) -> Dict[Tuple[Any, ...], RGB]:
    """Per-node colours: palette lookup, then depth and sibling shading."""
    colors: Dict[Tuple[Any, ...], RGB] = {}
    depth_denominator = max(n_levels - 1, 1)
    for node in nodes:
        base = palette.get(hue_values.get(node.path))
        if base is None:
            base = "#cccccc"
        depth_t = (depth_range * node.depth / depth_denominator
                   if n_levels > 1 else 0.0)
        if node.sibling_count > 1 and node.depth > 0:
            sibling_t = sibling_range * node.sibling_index / (
                node.sibling_count - 1)
        else:
            sibling_t = 0.0
        colors[node.path] = blend(base, depth_t + sibling_t)
    return colors
```

@dataclass(frozen=True)
class WedgeRecord:
    """One drawn wedge plus the metadata annotate strategies need.

    Unlike BarRecord, `patch` is held from construction rather than
    recovered: publiplots draws every Wedge itself, so there is no step
    that scans the axes and pairs records to artists by index. That step
    is where #103, #199, #236, #241, #254 and #262 all lived.

    Fields:
        patch: the matplotlib Wedge drawn for this node.
        path: keys from the root ring to this node.
        value: aggregated value; for an internal node, the sum of children.
        fraction_of_total: share of the whole chart.
        fraction_of_parent: share of this node's parent; equal to
            fraction_of_total at depth 0.
        theta0, theta1: angular extent in degrees, theta0 < theta1.
        r_inner, r_outer: radial band in axes data units.
        depth: 0 for the innermost ring.
        hue_color: the RGB the wedge was filled with. Named to match
            BarRecord/PointRecord so `_color.resolve_color` accepts a
            WedgeRecord unchanged -- it reads `.patch` and `.hue_color`,
            and its `anchor in ("inside", "center", "base")` branch already
            covers the wedge anchor vocabulary.
        hatch: the hatch pattern, or None.
        pull: radial offset as a fraction of the radius.
    """

    patch: Any
    path: Tuple[Any, ...]
    value: float
    fraction_of_total: float
    fraction_of_parent: float
    theta0: float
    theta1: float
    r_inner: float
    r_outer: float
    depth: int
    hue_color: Tuple[float, float, float]
    hatch: Optional[str]
    pull: float


@dataclass
class WedgeMeta:
    """Everything the wedge_values strategy needs about one plot call."""

    wedges: List[WedgeRecord]
    total: float
    donut: float
    center: Tuple[float, float]
    hue_active: bool
    hue_continuous: bool
    levels: Tuple[str, ...]
    source_frame: Optional[Any] = None

```python
"""Wedge artist construction, axes framing and meta emission."""
from __future__ import annotations

import math
from typing import Any, Dict, List, Optional, Sequence, Tuple

from matplotlib.axes import Axes
from matplotlib.patches import Wedge

from publiplots.annotate._cache import WedgeMeta, WedgeRecord
from publiplots.plot.wedge.geometry import WedgePlacement

MM_PER_INCH = 25.4


def pull_offset(placement: WedgePlacement, pull: float) -> Tuple[float, float]:
    """Displacement along the wedge's mid-angle, as a fraction of radius."""
    if not pull:
        return (0.0, 0.0)
    mid = math.radians((placement.theta0 + placement.theta1) / 2.0)
    return (pull * math.cos(mid), pull * math.sin(mid))


def draw_wedges(
    ax: Axes,
    placements: List[WedgePlacement],
    colors: Dict[Tuple[Any, ...], Tuple[float, float, float]],
    hatches: Dict[Tuple[Any, ...], Optional[str]],
    *,
    center: Tuple[float, float],
    pull: Dict[Tuple[Any, ...], float],
    alpha: float,
    edgecolor,
    linewidth: float,
) -> List[Wedge]:
    """Add one Wedge per placement, in draw order, and return them."""
    patches: List[Wedge] = []
    for place in placements:
        dx, dy = pull_offset(place, pull.get(place.node.path, 0.0))
        patch = Wedge(
            (center[0] + dx, center[1] + dy),
            place.r_outer,
            place.theta0,
            place.theta1,
            width=place.r_outer - place.r_inner,
            facecolor=colors[place.node.path],
            edgecolor=edgecolor,
            linewidth=linewidth,
            alpha=alpha,
            hatch=hatches.get(place.node.path),
        )
        ax.add_patch(patch)
        patches.append(patch)
    return patches


def build_wedge_meta(
    placements: List[WedgePlacement],
    patches: List[Wedge],
    colors: Dict[Tuple[Any, ...], Tuple[float, float, float]],
    hatches: Dict[Tuple[Any, ...], Optional[str]],
    pull: Dict[Tuple[Any, ...], float],
    *,
    total: float,
    donut: float,
    center: Tuple[float, float],
    levels: Sequence[str],
    hue_active: bool,
    hue_continuous: bool,
    source_frame: Optional[Any],
) -> WedgeMeta:
    """Pair each placement with the artist drawn for it, positionally --
    and safely, because both lists were produced by the loop above in the
    same pass. This is the only place the two meet, and neither is
    recovered from the axes.
    """
    if len(placements) != len(patches):
        raise AssertionError(
            f"wedge meta: {len(placements)} placements against "
            f"{len(patches)} patches"
        )
    parent_values = {p.node.path: p.node.value for p in placements}
    records = []
    for place, patch in zip(placements, patches):
        node = place.node
        parent_total = parent_values.get(node.parent, total) if node.parent \
            else total
        records.append(WedgeRecord(
            patch=patch,
            path=node.path,
            value=node.value,
            fraction_of_total=node.value / total if total else 0.0,
            fraction_of_parent=(node.value / parent_total
                                if parent_total else 0.0),
            theta0=place.theta0,
            theta1=place.theta1,
            r_inner=place.r_inner,
            r_outer=place.r_outer,
            depth=node.depth,
            hue_color=colors[node.path],
            hatch=hatches.get(node.path),
            pull=pull.get(node.path, 0.0),
        ))
    return WedgeMeta(
        wedges=records,
        total=total,
        donut=donut,
        center=center,
        hue_active=hue_active,
        hue_continuous=hue_continuous,
        levels=tuple(levels),
        source_frame=source_frame,
    )


def apply_cell_limits(ax: Axes, *, radius: float, aspect: str) -> None:
    """Frame the axes so the chart is circular.

    ``aspect="cell"`` leaves the aspect unconstrained and sets the data
    limits to the axes' own millimetre ratio. Measured on a 70x50mm cell,
    ``set_aspect("equal")`` shrinks the drawn box to 0.6008 of the figure
    against an allocated 0.8411 -- issue #101 -- while matching the cell
    keeps the full allocation and still renders a disc square to within a
    pixel. The tradeoff is that the limits are computed once, so an
    interactive resize would distort the circle; ``aspect="equal"`` is
    available for that case.
    """
    if aspect not in ("cell", "equal"):
        raise ValueError(
            f"aspect must be 'cell' or 'equal'; got {aspect!r}"
        )
    ax.set_axis_off()
    if aspect == "equal":
        ax.set_xlim(-radius, radius)
        ax.set_ylim(-radius, radius)
        ax.set_aspect("equal")
        return

    fig = ax.figure
    box = ax.get_position()
    w_mm = box.width * fig.get_figwidth() * MM_PER_INCH
    h_mm = box.height * fig.get_figheight() * MM_PER_INCH
    ratio = (w_mm / h_mm) if h_mm else 1.0
    ax.set_ylim(-radius, radius)
    ax.set_xlim(-radius * ratio, radius * ratio)
```

"""Pie and donut charts."""
from __future__ import annotations

from typing import Any, Callable, Dict, List, Optional, Sequence, Union

import pandas as pd
from matplotlib.axes import Axes
from matplotlib.colors import Normalize

from publiplots.annotate import annotate as _annotate
from publiplots.plot.wedge.colour import derive_colors, resolve_hue_values
from publiplots.plot.wedge.draw import (
    apply_cell_limits,
    build_wedge_meta,
    draw_wedges,
)
from publiplots.plot.wedge.geometry import (
    WedgeNode,
    build_nodes,
    layout,
    total_value,
)
from publiplots.themes.colors import resolve_continuous_cmap, resolve_palette_map
from publiplots.themes.hatches import resolve_hatch_map
from publiplots.themes.rcparams import resolve_param
from publiplots.utils import create_legend_handles
from publiplots.utils.legend_entries import (
    LegendEntry,
    resolve_legend_flags,
    stash_entry,
)
from publiplots.utils.plot_legend import render_entries, stash_continuous_hue

OTHER_LABEL = "Other"


def _bucket_small(frame, level, value, min_share):
    """Merge categories below ``min_share`` of the total into one row."""
    if not min_share:
        return frame
    sums = frame.groupby(level, observed=True)[value].sum()
    total = float(sums.sum())
    if total <= 0:
        return frame
    small = [k for k, v in sums.items() if (v / total) < min_share]
    if len(small) < 2:
        return frame
    out = frame.copy()
    out[level] = out[level].astype(object)
    out.loc[out[level].isin(small), level] = OTHER_LABEL
    return out


def pieplot(
    data: pd.DataFrame,
    x: Union[str, Sequence[str]],
    y: Optional[str] = None,
    hue: Optional[str] = None,
    *,
    ax: Optional[Axes] = None,
    donut: float = 0.0,
    start_angle: float = 90.0,
    direction: str = "clockwise",
    order: Optional[Sequence] = None,
    hue_order: Optional[Sequence] = None,
    sort: bool = False,
    pull: Union[float, Dict[Any, float], None] = None,
    min_share: float = 0.0,
    center_label: Union[str, Callable[[float], str], None] = None,
    aspect: str = "cell",
    palette: Optional[Union[str, Dict, List]] = None,
    hatch: Optional[str] = None,
    hatch_map: Optional[Dict[str, str]] = None,
    hatch_order: Optional[List[str]] = None,
    color: Optional[str] = None,
    edgecolor: Optional[str] = None,
    linewidth: Optional[float] = None,
    alpha: Optional[float] = None,
    legend: Union[bool, Dict] = True,
    legend_kws: Optional[Dict] = None,
    annotate: Union[bool, Dict, None] = None,
    title: str = "",
    **kwargs,
) -> Axes:
    """Draw a pie or donut chart.

    A pie is a one-level sunburst. ``x`` names the category column, ``y``
    the value (omitted, rows are counted), and ``hue`` what determines
    colour -- defaulting to ``x`` itself, which is what every pie does.
    For more than one level use :func:`publiplots.sunburstplot`.

    Parameters
    ----------
    data : pandas.DataFrame
        Tidy input. One row per observation, or one row per category when
        pre-aggregated.
    x : str
        Column naming each wedge. A sequence of length 1 is accepted;
        anything longer raises, naming ``sunburstplot``.
    y : str, optional
        Value column, summed within each category. When omitted, rows are
        counted.
    hue : str, optional
        Column determining colour. Defaults to ``x``. A categorical hue
        must be constant within a wedge.
    donut : float, default 0.0
        Inner radius as a fraction of the outer radius. ``0.5`` leaves a
        hole of half the radius, which is where ``center_label`` goes.
    start_angle : float, default 90.0
        Angle of the first wedge's leading edge, in degrees. 90 is twelve
        o'clock.
    direction : {'clockwise', 'counterclockwise'}, default 'clockwise'
    order : sequence, optional
        Explicit wedge order. Categories absent from the data are dropped;
        categories absent from ``order`` are filtered out.
    sort : bool, default False
        Order wedges by descending value. Cannot be combined with
        ``order``. Off by default so a pie keeps the category order of a
        bar panel drawn from the same frame.
    pull : float or dict, optional
        Radial offset as a fraction of the radius: a float for every
        wedge, or a dict keyed by category. Deliberately not a positional
        sequence.
    min_share : float, default 0.0
        Categories below this fraction of the total merge into a single
        ``"Other"`` wedge. Applies only when at least two categories fall
        below the threshold.
    center_label : str or callable, optional
        Text for the donut hole. A callable receives the total.
    aspect : {'cell', 'equal'}, default 'cell'
        ``'cell'`` matches the data limits to the axes' millimetre ratio,
        keeping the full cell width; ``'equal'`` uses matplotlib's aspect
        constraint, which survives an interactive resize but abandons part
        of the cell.

    Returns
    -------
    matplotlib.axes.Axes

    Notes
    -----
    ``hue`` means colour here and nothing else. In ``barplot`` it also
    controls how marks group, because grouping has no other parameter; in
    a wedge chart the structure lives in ``x``, so the two are separate.

    Examples
    --------
    >>> ax = pp.pieplot(data=df, x="kind", y="n")
    >>> ax = pp.pieplot(data=df, x="kind", y="n", donut=0.55,
    ...                 center_label="{:,.0f}".format)
    """
    from publiplots.layout.subplots import reject_figsize
    reject_figsize(kwargs)

    levels = [x] if isinstance(x, str) else list(x)
    if len(levels) > 1:
        raise ValueError(
            "pieplot: x= must name a single column; for a nested "
            "composition use pp.sunburstplot(x=[...])."
        )

    linewidth = resolve_param("edgewidth", linewidth)
    alpha = resolve_param("alpha", alpha)
    color = resolve_param("color", color)
    edgecolor = resolve_param("edgecolor", edgecolor)

    if ax is None:
        from publiplots.layout.subplots import subplots as _pp_subplots
        _, ax = _pp_subplots()

    frame = _bucket_small(data, levels[0], y, min_share) if min_share else data
    order_map = {levels[0]: list(order)} if order is not None else None

    nodes = build_nodes(frame, levels, y, order=order_map, sort=sort)
    if min_share and any(n.path[0] == OTHER_LABEL for n in nodes):
        # The bucket sorts last whatever the resolver decided, then the
        # sibling indices are renumbered so the colour derivation sees a
        # consistent run. (Inert on one ring, but wrong indices here would
        # become wrong colours the moment the sunburst reuses this path.)
        ordered = ([n for n in nodes if n.path[0] != OTHER_LABEL]
                   + [n for n in nodes if n.path[0] == OTHER_LABEL])
        nodes = [
            WedgeNode(path=n.path, value=n.value, depth=n.depth,
                      parent=n.parent, sibling_index=i,
                      sibling_count=len(ordered))
            for i, n in enumerate(ordered)
        ]
    total = total_value(nodes)
    places = layout(nodes, start_angle=start_angle, direction=direction,
                    donut=donut, n_levels=1)

    hue_values, hue_continuous = resolve_hue_values(frame, levels, hue, nodes)
    hue_levels = list(dict.fromkeys(
        hue_values[n.path] for n in nodes if n.path in hue_values))
    hue_norm = None
    if hue_continuous:
        # A numeric hue maps through a colormap rather than a palette. Build
        # a value -> colour dict so derive_colors' lookup is unchanged.
        cmap = resolve_continuous_cmap(None, color=color)
        lo, hi = min(hue_levels), max(hue_levels)
        hue_norm = Normalize(vmin=lo, vmax=hi if hi > lo else lo + 1.0)
        palette_map = {v: cmap(hue_norm(v)) for v in hue_levels}
    else:
        if hue_order is not None:
            hue_levels = [v for v in hue_order if v in hue_levels]
        # resolve_palette_map returns a dict palette VERBATIM, so a partial
        # dict would leave every unnamed level without a colour. Resolve
        # the defaults first, then overlay the caller's entries, so
        # palette={"Other": "#123456"} recolours one wedge instead of
        # greying the rest.
        if isinstance(palette, dict):
            palette_map = {**resolve_palette_map(hue_levels, None), **palette}
        else:
            palette_map = resolve_palette_map(hue_levels, palette)
        if min_share and OTHER_LABEL not in (palette or {}):
            palette_map = {**palette_map, OTHER_LABEL: "#b4b4b4"}

    colors = derive_colors(nodes, hue_values, palette_map,
                           depth_range=0.0, sibling_range=0.0, n_levels=1)
    hatch_map_resolved = resolve_hatch_map(
        hue_levels, hatch, hatch_map, hatch_order) if hatch else {}
    hatches = {n.path: hatch_map_resolved.get(hue_values.get(n.path))
               for n in nodes}

    if pull is None:
        pull_map = {}
    elif isinstance(pull, dict):
        pull_map = {n.path: float(pull.get(n.path[0], 0.0)) for n in nodes}
    else:
        pull_map = {n.path: float(pull) for n in nodes}

    patches = draw_wedges(
        ax, places, colors, hatches, center=(0.0, 0.0), pull=pull_map,
        alpha=alpha, edgecolor=edgecolor, linewidth=linewidth,
    )
    ax._publiplots_wedge_meta = build_wedge_meta(
        places, patches, colors, hatches, pull_map,
        total=total, donut=donut, center=(0.0, 0.0), levels=levels,
        hue_active=True, hue_continuous=hue_continuous, source_frame=data,
    )

    max_pull = max(pull_map.values(), default=0.0)
    apply_cell_limits(ax, radius=1.0 + max_pull + 0.05, aspect=aspect)

    if donut and center_label is not None:
        text = center_label(total) if callable(center_label) else center_label
        ax.text(0.0, 0.0, text, ha="center", va="center")

    if title:
        ax.set_title(title)

    flags = resolve_legend_flags(legend)
    if hue_continuous and hue_levels:
        stash_continuous_hue(
            ax,
            name=hue if hue is not None else levels[0],

```python
"""The wedge_values annotate strategy."""
from __future__ import annotations

import math
from typing import List, Optional

from matplotlib.axes import Axes
from matplotlib.text import Text

from publiplots.annotate._cache import WedgeMeta
from publiplots.annotate._color import resolve_color
from publiplots.themes.rcparams import resolve_param

_VALID_ANCHORS = {"inside", "outside", "auto"}
_VALID_BASES = {"total", "parent"}
_VALID_ROTATIONS = {"tangential", "radial"}

# Sentinel the dispatcher hands back when the caller passed no `fmt`. A
# real format spec cannot collide with it, and it is what distinguishes
# "label the share as a percentage" (the default) from "format the value
# with this spec".
_WEDGE_DEFAULT_FMT = "__wedge_percent__"

# A wedge narrower than this cannot hold a label; `auto` sends it outside.
# Chosen so a two-digit percentage fits at the default 7pt font on a 40mm
# chart, measured rather than guessed -- see the gallery page.
_MIN_INSIDE_DEGREES = 18.0


def _meta(ax: Axes) -> WedgeMeta:
    meta = getattr(ax, "_publiplots_wedge_meta", None)
    if meta is None:
        raise ValueError(
            "annotate(kind='wedge_values') requires an axes drawn by "
            "pp.pieplot. There is no introspection fallback for a foreign "
            "ax.pie(): recovering wedges from the axes is the step that "
            "produced the annotate pairing bugs this design avoids."
        )
    return meta


def _format(value: float, fmt: str) -> str:
    if "{" in fmt:
        return fmt.format(value)
    return format(value, fmt)


def _upright(angle: float) -> float:
    """Keep derived text readable by flipping anything upside-down."""
    angle = (angle + 180.0) % 360.0 - 180.0
    if angle > 90.0:
        return angle - 180.0
    if angle < -90.0:
        return angle + 180.0
    return angle


def _wedge_values_strategy(
    ax: Axes,
    *,
    fmt: str,
    anchor,
    offset: float,
    color,
    pad: float,
    rotation=0.0,
    basis: Optional[str] = None,
    **text_kws,
) -> List[Text]:
    meta = _meta(ax)
    anchor = anchor if anchor is not None else "auto"
    if anchor not in _VALID_ANCHORS:
        raise ValueError(
            f"wedge_values anchor must be one of {sorted(_VALID_ANCHORS)}; "
            f"got {anchor!r}"
        )
    basis = basis if basis is not None else "total"
    if basis not in _VALID_BASES:
        raise ValueError(
            f"basis must be one of {sorted(_VALID_BASES)}; got {basis!r}"
        )
    if isinstance(rotation, str) and rotation not in _VALID_ROTATIONS:
        raise ValueError(
            f"rotation must be a finite number of degrees or one of "
            f"{sorted(_VALID_ROTATIONS)}; got {rotation!r}"
        )

    edgewidth = resolve_param("edgewidth", None)
    edgecolor = resolve_param("edgecolor", None)
    texts: List[Text] = []

    for record in meta.wedges:
        share = (record.fraction_of_total if basis == "total"
                 else record.fraction_of_parent)
        # Percentage is the default; an explicit spec formats the value.
        if fmt == _WEDGE_DEFAULT_FMT:
            label = format(share * 100.0, ".1f") + "%"
        else:
            label = _format(record.value, fmt)

        mid = math.radians((record.theta0 + record.theta1) / 2.0)
        span = record.theta1 - record.theta0
        place_outside = (
            anchor == "outside"
            or (anchor == "auto" and span < _MIN_INSIDE_DEGREES)
        )
        cx, cy = record.patch.center
        if place_outside:
            r = record.r_outer + 0.18
            ha = "left" if math.cos(mid) >= 0 else "right"
            x0 = cx + record.r_outer * math.cos(mid)
            y0 = cy + record.r_outer * math.sin(mid)
            x1 = cx + r * math.cos(mid)
            y1 = cy + r * math.sin(mid)
            ax.plot([x0, x1], [y0, y1], color=edgecolor,
                    linewidth=edgewidth, zorder=record.patch.get_zorder() + 1)
            x, y = x1, y1
        else:
            r = (record.r_inner + record.r_outer) / 2.0
            ha = "center"
            x = cx + r * math.cos(mid)
            y = cy + r * math.sin(mid)

        # Flipping upside-down text applies only to the derived
        # orientations. An explicit `rotation=120` is the caller's choice
        # and is passed through untouched.
        if rotation == "tangential":
            angle = _upright(math.degrees(mid) - 90.0)
        elif rotation == "radial":
            angle = _upright(math.degrees(mid))
        else:
            angle = rotation

        texts.append(ax.text(
            x, y, label,
            ha=ha, va="center", rotation=angle,
            # resolve_color reads `.patch` and `.hue_color` off the record
            # and branches on the anchor, so a WedgeRecord works unchanged.
            # Pass the anchor this label actually used, not the requested
            # one: under `auto` they differ per wedge, and the contrast
            # calculation is only correct for a label drawn over a fill.
            color=resolve_color(
                record,
                color,
                "outside" if place_outside else "inside",
                ax,
                hue_active=meta.hue_active,
            ),
            **text_kws,
        ))
    return texts
```

```markdown
- **`pp.pieplot` — pie and donut charts in the publiplots visual
  language** (#268). `matplotlib.axes.Axes.pie` ignores the palette, the
  theme edge and `pp.legend`, so a composition panel could not be drawn to
  match its siblings; the legend in particular could not be worked around,
  because wedges were never stashed and so could not join a shared band.

  `x` names the category column, `y` the value (omitted, rows are
  counted), and `hue` what determines colour — defaulting to `x`, which is
  what every pie does. A pie is a one-level sunburst, and `hue` means
  colour and nothing else: unlike `barplot`, where `hue` also controls how
  marks group, a wedge chart keeps its structure in `x`.

  `donut=` opens a hole and `center_label=` fills it. `pull=` offsets a
  wedge and is keyed by category rather than positional. `min_share=`
  collapses the long tail into one `"Other"` wedge. `order=` and `sort=`
  are mutually exclusive, and `sort` is **off** by default so a pie keeps
  the category order of a bar panel drawn from the same frame — the
  correspondence that motivated the issue.

  Labels come from `pp.annotate(ax, "wedge_values")`, defaulting to the
  percentage rather than the raw value, with `anchor="auto"` keeping a
  label inside its wedge when it fits and moving it out with a leader line
  when it does not.

  The chart is circular without losing cell width. `ax.set_aspect("equal")`
  shrinks the drawn box to 0.6008 of the figure against an allocated
  0.8411 on a 70x50mm cell (#101); because the renderer draws its own
  wedges and `ax.get_position()` reports exact millimetres before any
  draw, the limits are matched to the cell instead, which renders a disc
  square to within a pixel and keeps the full allocation. `aspect="equal"`
  selects the matplotlib behaviour for anyone who needs it to survive an
  interactive resize.

  Each annotate record holds its artist from construction rather than
  recovering it from the axes afterwards. That recovery step — scanning
  and pairing by index — is where #103, #199, #236, #241, #254 and #262
  all lived, and it does not exist here. For the same reason there is no
  introspection fallback: `wedge_values` on an axes publiplots did not draw
  raises and says so.
```
